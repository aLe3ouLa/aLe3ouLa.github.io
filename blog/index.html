/* shadow hugs the real shape, not the box */
.icon { filter: drop-shadow(4px 4px 8px crimson); }

/* stack them too */
filter:
  drop-shadow(1px 1px 0 navy)
  drop-shadow(-1px -1px 0 navy);

filter: drop-shadow()

box-shadow only knows rectangles. drop-shadow follows the actual shape of your element.
